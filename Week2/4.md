Object overhead chiếm 16 bytes.
Inner class extra reference mang theo tham chiếu ẩn đến BST bên ngoài, chiếm 8 bytes.
Các biến tham chiếu khác bên trong Node: Key, Value, Parent, Left, Right. Mỗi cái chiếm 8 bytes -> 5 x 8 = 40 bytes.
Biến count chiếm 4 bytes.
Sum = 16 + 8 + 40 + 4 = 68 bytes.
Nhưng java cấp phát bộ nhớ theo bội số của 8 nên 68 được cấp thành 72 bytes.
